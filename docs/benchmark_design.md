# Benchmark design for the order-parameter review

The manuscript review and next execution steps are in
[research_workflow.md](research_workflow.md). That follow-on plan refines the
statistical evaluation, seed-label audit, thermal sampling and CV assessment
below, and takes precedence where this initial design differs.

This is the plan for Chapter 5 ("A unified benchmark") of
`manuscript/new.tex`. Every order parameter is computed with one
implementation (SolOrder), one settings registry and one analysis pipeline,
so the differences we report come from the parameters themselves and not from
codes, cutoffs or water models.

## Questions the benchmark answers

| # | Question | Main output |
|---|---|---|
| Q1 | Which phase pairs can each parameter separate, ideally and at finite temperature? | Separability heat map (F1) |
| Q2 | Which parameters carry redundant information? | Correlation dendrogram (F2) |
| Q3 | Which pair of parameters gives the most separation for a given task? | Best-pair maps (F3) |
| Q4 | How strongly do results depend on cutoffs, averaging, temperature and water model? | Sensitivity curves (F4, F5) |
| Q5 | How well do per-molecule labels match the ground truth in mixed ice/liquid systems? | Seed-test accuracy (F7) |
| Q6 | What does each parameter cost, and is it usable as a collective variable? | Cost scaling (F6), smoothness table (T3) |

## Principles

1. **Settings fixed in advance.** Each parameter's default settings are the
   ones used in its original paper, recorded in a registry before any
   separability is computed. Tuned settings appear only in the sensitivity
   study and are labeled as tuned.
2. **Fair data splits.** Molecules in the same frame are correlated. Training
   and test sets for any classifier are therefore split by trajectory or by
   time block, never by molecule. Uncertainties come from a block bootstrap
   over frames.
3. **Clear inputs.** Each result states whether it uses oxygen positions only
   or full molecules. Parameters that need hydrogens (F4, hydrogen bonds,
   P(theta), Q_T) are excluded from mW results.
4. **Labels are not distributions.** Classifiers (CHILL, CHILL+, PTM) are
   scored against ground-truth labels. Continuous parameters are scored by
   separability.
5. **Provenance.** Each output records the SolOrder version, the input file
   SHA-256 and the registry hash, as the GenIce manifest already does.

## Datasets

### D1: Ideal crystals (GenIce2)

- **Existing:** 11 structures (Ih, Ic, II, III, V, VI, VII, VIII, XII, XVII,
  empty sI), generated by `scripts/generate_genice_fixtures.py`.
- **To add** (all available in the local GenIce2 install): IV, IX, XI, XIII,
  XIV, XVI, sII, sH.
- **Proton order/disorder pairs:** Ih/XI, III/IX, V/XIII, VII/VIII and
  XII/XIV. These test whether parameters built only from oxygen positions can
  tell proton-ordered from proton-disordered phases. The expected answer is
  that they cannot, which is itself worth reporting.
- **Seeds:** 5 GenIce seeds per proton-disordered phase, so proton
  configuration is a measured source of variance rather than one fixed draw.
- **Box size:** every box edge must exceed twice the largest cutoff used,
  6 A for descriptors. This means at least 12 A; aim for at least 25 A where
  feasible.

### D2: Thermalized and inherent structures (TIP4P/Ice)

- **Simulation engine:** OpenMM, reusing the TIP4P/Ice setup in
  `ice_nucleation_pg/inputs/tip4pice.xml`.
- **Crystals:** start from D1 structures and run NPT with an anisotropic
  barostat. Each phase sits at a state point inside its TIP4P/Ice stability
  region.
- **Liquid:** liquid at the same T and P as each crystal, for ice-versus-liquid
  separability.
- **Protocol:** 2 ns equilibration, then 10 ns production, saving every
  10 ps. Analysis uses frames spaced at least 2x the measured integrated
  autocorrelation time of Q and q6.
- **Stability check:** a run counts as stable if density and the CHILL+ ice
  fraction show no drift over the production run. Unstable phases are
  reported as such and excluded from D2.
- **Inherent structures:** energy-minimize 50 frames per phase. These sit
  between the ideal and thermal cases and reproduce the minimized structures
  used in the earlier manuscript.
- **Temperature series:** for Ih, Ic, sI and their liquids, run 200, 230, 250
  and 260 K at 1 bar. This shows how separability degrades approaching
  melting (TIP4P/Ice T_m of about 270 K).

Candidate state points (to be confirmed against the TIP4P/Ice phase diagram
before production):

| Phase | T (K) | P (bar) | Note |
|---|---:|---:|---|
| Ih, Ic, sI (empty) | 230 | 1 | Ic and empty sI are metastable |
| II | 230 | 3000 | from earlier manuscript runs |
| III | 230 | 3000 | from earlier manuscript runs |
| V | 230 | 6000 | from earlier manuscript runs |
| VI | 230 | 8000 | from earlier manuscript runs |
| VII, VIII | TBD | TBD | GPa range |
| XII, IV, XVII | TBD | TBD | metastable; check survival |

### D3: Second water model (sensitivity only)

- **TIP4P/2005:** Ih, Ic, VI and liquid, at the same reduced undercooling as
  D2.
- **mW:** Ih, Ic and liquid, reusing `ice_nucleation_pg/mw`. Oxygen-only
  parameters only.

### D4: Mixed systems with per-molecule ground truth (already exists)

`ice_nucleation_pg/seedtest` provides TIP4P/Ice systems at 220 K:

- Spherical Ih, Ic and stacking-disordered seeds of about 50, 100 and 200
  molecules, placed in liquid.
- Bulk crystals.
- Thermal frames and quenched frames.
- `truth.npz`, which gives per-molecule seed membership, interior flags and
  local stacking (hexagonal or cubic).

This is the ground truth for Q5.

### D5: Nucleation trajectories (already exist)

- Converged PathGennie reactive paths: `ck_M_final.h5` (Ih) and
  `ck_O_Ic_final.h5` (Ic, NPT).
- TIP4P/Ice metadynamics walkers at 220 K.

Used only for the application section: how large a cluster each method
reports along the same path. No ground truth is assumed.

## Parameter registry

The registry is a single file, `benchmarks/registry.py` (a Python module, so
entries are directly callable and no YAML dependency is needed). Each entry gives
the SolOrder call, its default arguments, the source paper, whether
hydrogens are needed, the output kind (scalar, vector or label) and whether
the parameter is smooth.

| Group | Parameters (defaults) |
|---|---|
| Radial | density; CN (3.5 A); smooth CN (r0=3.5, n=12, m=28); d5; LSI (3.7 A); Voronoi density and asphericity; entropy and local entropy (5 A) |
| Angular | Q and local-average Q; translational order; P(theta) moments; bond angle B; angle histogram H; angular Fourier; A1-A3 |
| H-bond / topology | donated, accepted and total H-bond counts; F4 (3.5 A); graph degree features; smallest-ring fractions (H-bond network, up to 10-rings); zeta (3.5 A, 30 deg) |
| Bond-orientational | q3, q4, q6, local-average q_l, w_l and normalized w_l (l = 3, 4, 6; cutoff 3.5 A and 12 nearest neighbors); crystalline connections |
| Template / symmetry | CSP (12 neighbors), neighbor-distance D |
| Molecular | Q_T (needs dipole input) |
| Labels | CHILL, CHILL+, PTM |
| Vector descriptors | SOAP (n=8, l=6, 6 A), ACSF, LMBTR |

Vector descriptors are computed on a 100-frame subsample per condition to
limit storage. Learned classifiers (DeepIce, GCIceNet) are included only if
published pretrained weights can be run unchanged. Otherwise they are
discussed from the literature only.

## Metrics

1. **Pairwise separability (main measure for scalar parameters):** the
   two-sample Kolmogorov-Smirnov statistic D, from 0 (identical
   distributions) to 1 (fully separable). It needs no binning, which matters
   for the near-delta distributions of ideal crystals, and (1 + D)/2 is
   the balanced accuracy of the best single threshold chosen on the same
   data, reported as an *oracle score*; held-out scores (threshold fitted on
   another run) are reported separately in `separability_heldout.csv`. Ideal
   structures are jittered (0.02 A Gaussian, once per GenIce seed) so separability
   is judged at a stated resolution rather than at coordinate rounding. The
   histogram overlap and Jensen-Shannon distance are reported in the SI.
2. **Multi-class balanced accuracy:** a standardized logistic regression for
   each parameter alone and for each group. The same classifier is used for
   vector descriptors after PCA to 10 dimensions, so the comparison is about
   information content, not model capacity. A gradient-boosting run on all
   scalars gives the upper reference.
3. **Best pairs:** all scalar pairs (about 450) are scored by 2D logistic
   regression for three tasks: ice versus liquid, Ih versus Ic, and the
   high-pressure polymorphs.
4. **Redundancy:** a Spearman correlation matrix and its hierarchical
   clustering on pooled D2 data, with mutual information in the SI.
5. **Label accuracy (D4):** per-molecule precision and recall against
   `truth.npz`, reported separately for interior and surface molecules.
   Also reported: detected seed size against true size, and stacking accuracy
   (hexagonal or cubic layers).
6. **Collective-variable suitability:**
   - Whether the parameter is smooth, from its definition.
   - Noise sensitivity: the change in the parameter under 0.01 A Gaussian
     displacements, relative to its spread between phases.
   - Along D5: whether the global value rises steadily with the largest
     cluster size.
   - If the shooting runs give committor estimates: the correlation between
     the parameter and the committor.
7. **Uncertainty:** 95% intervals from a block bootstrap over frames
   (1000 resamples), and over independent runs or seeds where available.

## Sensitivity studies

- **Cutoffs:** scan 3.0-4.0 A in 0.1 A steps for CN, F4, LSI and q_l; vary
  the neighbor count over 4, 8, 12 and 16 for q_l and CSP.
- **Averaging:** each parameter with and without local averaging.
- **Temperature:** Separability against T/T_m, from the D2 temperature series.
- **Water model:** Separability ranking in TIP4P/Ice against TIP4P/2005 and mW, using
  Kendall's tau of the parameter ranking.

## Cost

- **System sizes:** replicate GenIce Ih supercells to about 10^3, 10^4 and
  10^5 waters.
- **Settings:** n_jobs = 1, 4 and 20, with thread and process backends.
- **Reported:** wall time per molecule per frame and peak memory, on stated
  hardware (20 cores).
- **Cross-check:** q6, CHILL+ and PTM are also timed and checked for
  agreement in freud, OVITO and PLUMED. This doubles as a correctness check.

## Pipeline

```
benchmarks/
  registry.py            parameter settings (fixed before analysis)
  compute.py             datasets x registry -> per-molecule tables (cache/, not committed)
  metrics.py             KS separability, bootstrap, redundancy, label scores
  figures.py             figures, reading only results/*.csv
  results/               small CSV and figures, committed
  build/                 (later) GenIce generation, OpenMM inputs, minimization
```

Large inputs stay where they are and are referenced by path and hash, as
`scripts/validate_nucleation.py` already does.

## Prerequisites in SolOrder

- ~~Russo-Tanaka zeta and ring statistics.~~ Done: `op.zeta()` and
  `op.ring_statistics()`.
- A batch interface that evaluates several registry entries per frame while
  reusing one neighbor search. This is the main computational saving.
- An independent raw w_l test, and an explicit threshold argument for
  crystalline connections.

## Milestones

1. **Pilot, no new simulations (done).** Run the full pipeline on the existing D1
   (11 phases) and D4 seed test: compute.py, metrics.py, F1, F2 and F7. This
   checks the pipeline and gives early results.
2. **Extended D1 (done: 18 phases x 5 seeds; XVI dropped as identical to empty sII).** Add the remaining GenIce phases with multiple seeds, plus
   zeta and ring statistics.
3. **D2 thermalized MD.** Confirm state points, run stability checks, run
   production and minimization.
4. **Sensitivity and cost.** D3, the cutoff scans and the scaling runs.
5. **Application.** D5 paths, optional D6, and the final figures.

## Risks

- **Phase instability.** Some phases may not be stable in TIP4P/Ice at
  accessible conditions. Report this and keep them in D1 only.
- **Settings bias.** Fixing settings in advance (principle 1) prevents
  quietly tuning parameters toward a preferred ranking.
- **Correlated samples.** Block splits and block bootstrap (principle 2)
  keep accuracies from being inflated by correlated molecules.
- **Storage.** Scalars at float32 for about 20 conditions x 10^3 frames x
  10^3 waters take a few GB. Vector descriptors are limited to subsamples.
